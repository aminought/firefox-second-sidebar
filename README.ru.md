Скрипт Firefox userChrome.js, добавляющий вторую боковую панель с веб-панелями как в Vivaldi/Edge/Floorp, но лучше.

## Мотивация

Я пробовал различные браузеры, такие как Vivaldi, Edge, Floorp и Zen, и у всех есть одно общее — без боковой панели я не могу представить использование браузера. К сожалению, Firefox, который больше всего соответствует моим потребностям, имеет довольно неудовлетворительную боковую панель. Поэтому я решил создать свою, с блэкджеком и девушками!

## Возможности

### Боковая панель

- Действия: `Показать` • `Скрыть`
- Настройка через [Настроить панель инструментов...](https://support.mozilla.org/ru/kb/customize-firefox-controls-buttons-and-toolbars)
- Настройки:
  - Общие: `Позиция (Слева / Справа)` • `Ширина`
  - Видимость: `Автоматически скрывать боковую панель` • `Поведение автоматического скрытия (Встроенное / Наложение)` • `Скрывать веб-панель при скрытой боковой панели` • `Горячая клавиша для скрытия/показа боковой панели`
  - Веб-панель: `Смещение плавающей панели по умолчанию` • `Позиция новой панели (Перед кнопкой «плюс» / После кнопки «плюс»)` • `Показывать подсказку геометрии`
  - Кнопка веб-панели: `Индикатор контейнера (Выключено / Слева / Справа / Сверху / Снизу / Вокруг)` • `Подсказка (Выключено / Заголовок / URL / Заголовок и URL)` • `Показывать полный URL в подсказке`
  - Панель инструментов веб-панели: `Автоматически скрывать кнопку «вперёд»` • `Автоматически скрывать кнопку «назад»`
  - Анимации: `Анимировать боковую панель` • `Анимировать панель инструментов веб-панели`

### Веб-панели

- Действия: `Создать` • `Удалить` • `Редактировать` • `Изменить позицию и размер` • `Сбросить позицию и размер` • `Выгрузить` • `Заглушить` • `Включить звук` • `Закрепить` • `Открепить` • `Изменить масштаб` • `Назад` • `Вперёд` • `Обновить` • `Домой`
- Поддержка расширений
- Поддержка всплывающих уведомлений (разрешения на микрофон/камеру/геолокацию и т.д.)
- Настройки:
  - Общие: `URL` • `Мульти-аккаунт контейнер` • `Временная` • `Мобильный вид` • `Масштаб`
  - Заголовок: `Динамический` • `Установить статический заголовок`
  - Значок: `Динамический` • `Установить статический значок`
  - Позиция и размер: `Режим (Плавающая / Закреплённая)` • `Всегда поверх всех` • `Якорь позиции` • `Горизонтальное смещение` • `Вертикальное смещение` • `Ширина` • `Высота`
  - Загрузка: `Загружать в память при запуске` • `Восстановить последнюю открытую страницу` • `Выгружать из памяти при закрытии` • `Периодическая перезагрузка`
  - Горячая клавиша: `Горячая клавиша для скрытия/показа веб-панели`
  - CSS-селектор: `Включить` • `Установить CSS-селектор`
  - Скрыть элементы: `Скрыть панель инструментов` • `Скрыть значок звука` • `Скрыть значок уведомления`

## Установка

### Установка в один клик (Windows, рекомендуется)

Открыть PowerShell от имени **администратора** и выполнить:

```powershell
irm https://raw.githubusercontent.com/aminought/firefox-second-sidebar/master/install.ps1 | iex
```

Скрипт автоматически выполнит:

1. Скачает fx-autoconfig и Second Sidebar с GitHub
2. Определит каталог установки Firefox и папку профиля
3. Установит программные файлы и файлы профиля fx-autoconfig
4. Установит скрипт Second Sidebar
5. Проверит установку

> **Права администратора**: `config.js` fx-autoconfig необходимо скопировать в `C:\Program Files\Mozilla Firefox\`, что требует прав администратора.

**Удаление:**

```powershell
irm https://raw.githubusercontent.com/aminought/firefox-second-sidebar/master/uninstall.ps1 | iex
```

### Ручная установка

1. Установить [fx-autoconfig](https://github.com/MrOtherGuy/fx-autoconfig).
2. Скопировать содержимое каталога `src/` (`second_sidebar/` и `second_sidebar.uc.mjs`) в `chrome/JS/`.
3. Включить `toolkit.legacyUserProfileCustomizations.stylesheets` и `dom.allow_scripts_to_close_windows` в `about:config`.
4. [Очистить](https://github.com/MrOtherGuy/fx-autoconfig?tab=readme-ov-file#deleting-startup-cache) кэш запуска.
5. Наслаждайтесь!

## Локализация

Скрипт поддерживает несколько языков и автоматически отображает интерфейс на языке Firefox.

### Добавить новый язык

1. Скопировать `en-US.mjs` в новый файл (напр. `it.mjs`)
2. Заменить английские значения переводами (ключи не менять)
3. Импортировать и зарегистрировать новый язык в `index.mjs`
4. Отправить PR
